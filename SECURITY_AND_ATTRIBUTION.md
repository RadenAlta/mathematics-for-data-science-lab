# Public portfolio content policy

This package is designed to be publicly shareable without exposing the original Dicoding submission source, question PDFs, or knowledge-check answer spreadsheet. The assessment ZIP supplied by the learner is intentionally kept outside this public repository.

No passwords, API keys, or private data are required. All case-study datasets are synthetic and deterministic. The reviewer achievement is attributed to the learner's course result; the portfolio reimplementations have separate, transparently documented outputs.

This repository does not grant permission to copy its contents into graded submissions. Course material and trademarks remain with their respective rights holders.
